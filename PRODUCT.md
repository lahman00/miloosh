# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

People comparing software for their work or business. The owner wants visitors to feel comfortable, trust the research and continue to suitable software providers. More precise audience segmentation remains open.

## Product Purpose

Miloosh is an existing software research and affiliate website. Its catalogue supports software search, alternatives, side-by-side comparisons, decision guides and a recommendation questionnaire.

## Capabilities and Constraints

Existing Next.js 16.3.5 / React / Tailwind 4 implementation. Preserve real product facts, existing URLs, source dates, affiliate tracking and clear disclosure. No invented customers, ratings, firsthand tests or conversion claims. Public copy remains English, matching the existing site; owner communication is Hebrew.

## Brand Commitments

Keep the Miloosh name and existing M mark. The owner approved Ramp as the visual reference: light warm surfaces, large typography and confidence. The owner delegated implementation choices. This is an authorized redesign of the existing site.

## Evidence on Hand

data/software contains the existing sourced catalogue. Existing guides, categories and comparisons are the content base. public/logo-icon.png is the existing mark. No separate supplied brand guide or testimonials.

## Product Principles

- Help readers choose suitable software before inviting a provider visit.
- Keep tradeoffs and sources accessible.
- Make search, browsing and comparison easy on phones as well as desktop.
- Present affiliate relationships honestly.
