# Buyer-depth recovery Wave 2 — October 1, 2026

Status: LOCALLY VERIFIED, NOT YET DEPLOYED when this receipt was written.

## Why these two existing pages

This is a bounded visibility-recovery intervention, not catalog expansion. The private same-property Search Console loss map identified /software/zoho-projects and /software/elevenlabs as unprotected, previously visible software pages with active affiliate relationships and no existing source-linked buyer checklist. Exact private GSC exports remain outside the public repository.

No new public URL, category, partner application or ranking slot was created.

## Zoho Projects

The existing page now has three documentation-based buyer checks:
- whether the Free five-user and three-project ceiling fits the production team;
- whether Client, Read-Only, Resource or Lite-user requirements force another edition;
- what must remain usable if the account later downgrades or switches.

The checks preserve a stay-with-Zoho path and do not claim a hands-on migration.

## ElevenLabs

The existing page now has three documentation-based buyer checks:
- commercial-use rights versus the Free plan;
- shared-credit consumption across products and models rather than a universal minutes conversion;
- rollover, downgrade/cancel and Pay As You Go boundaries.

The checks do not claim generated-output quality testing or customer savings.

## Discovery without inventory expansion

Two existing guides gained one contextual path each:
- small-team project management to the Zoho Projects buyer checklist;
- AI voice tools for creators to the ElevenLabs buyer checklist.

The ranked shortlists are unchanged. These decision links use ordinary native anchors so cross-page hash navigation is stable.

Those product-record edits were removed before release. The final build changes exactly four rendered public routes: the two software pages and the two source guides. There are no protected rendered conflicts, canonical changes, H1 changes, added routes or missing routes.

The sitemap keeps the same URL inventory. Wave-2 software and source-guide content dates may advance, but comparison lastmod dates advance only for the earlier buyer-depth wave whose shared product records actually changed comparison output.
